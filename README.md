# Éditeur PDF

Outil gratuit pour remplir et modifier des PDF directement dans le navigateur : ajout de texte, formes, signatures manuscrites, et modification du texte existant (l'ancien texte est réellement supprimé du fichier).

**Utiliser l'outil :** https://thorn96.github.io/EDITPDF/

Tout se passe dans le navigateur : les PDF ne sont envoyés sur aucun serveur. Chrome ou Edge conseillés (ils permettent de réutiliser la police d'origine du PDF).
